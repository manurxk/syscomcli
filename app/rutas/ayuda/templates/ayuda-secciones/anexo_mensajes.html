Avisos de validación del sistema

Cuando un dato no cumple una regla, el sistema no lo guarda y muestra un aviso en rojo en la misma pantalla. Los avisos son de pocos tipos, y en todas las pantallas dicen lo mismo. Léalo: siempre nombra el campo o el problema. Se corrige y se vuelve a guardar; no se pierde lo ya escrito.

{% for m in mensajes %}

{{ m.titulo }}

{{ m.significa }}

Ejemplo: {{ m.ejemplo }}

Qué hacer: {{ m.hacer }}

Pantallas donde puede aparecer:

    {% for i in m.lista %}
  • {{ i }}
    • {% endfor %}
{% for archivo, pantalla in m.capturas %} {{ figura('mensajes/' ~ archivo, 'Aviso «' ~ m.titulo|lower ~ '» en ' ~ pantalla) }} {% endfor %} {% endfor %}

Si el aviso no coincide con ninguno de estos tipos, es una regla propia de esa pantalla (por ejemplo, una cita sin turno libre o una caja que no está abierta). El mensaje explica qué falta; si no queda claro, avise al administrador con el texto exacto que vio.
