Timbrados

Autorización de la SET para emitir facturas. Sin timbrado vigente no se puede facturar. La configura un administrador.

{{ figura('timbrados/01_listado.jpg', 'Timbrados: ① Agregar') }} {{ figura('timbrados/02_agregar.jpg', 'Nuevo timbrado') }}
  1. Presione Agregar.
  2. Escriba el N° Timbrado SET (8 dígitos) y el Código de Establecimiento (3 dígitos), como figuran en la constancia.
  3. Ponga Fecha inicio y Fecha vencimiento.
  4. Deje Activo y presione Guardar.
  • Después cree al menos un Punto de Expedición para ese timbrado.
  • Editar (lápiz) o eliminar (botón rojo).

Cargue el timbrado nuevo antes de que venza el actual, para no quedarse sin facturar.
