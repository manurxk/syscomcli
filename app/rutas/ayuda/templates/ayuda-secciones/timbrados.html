Timbrados

El timbrado es la autorización de la SET para emitir facturas. Sin un timbrado vigente no se puede facturar. Esta pantalla la configura un administrador.

¿Cómo cargo un timbrado?

  1. Presione Agregar.
  2. Escriba el N° Timbrado SET (8 dígitos) y el Código de Establecimiento (3 dígitos, por ejemplo 001), tal como figuran en la constancia de la SET.
  3. Ponga la Fecha inicio y la Fecha vencimiento de la vigencia.
  4. Deje marcado Activo y presione Guardar.

Después cree al menos un Punto de Expedición para ese timbrado.

Cuando el timbrado esté por vencer, tramite el nuevo en la SET y cárguelo antes de la fecha de vencimiento, para no quedarse sin poder facturar.

¿Cómo corrijo o doy de baja un timbrado?

Use el botón del lápiz para editarlo, o el botón rojo para eliminarlo.
