Puntos de Expedición

El punto de expedición es el lugar desde donde se emiten facturas, por ejemplo una caja o un consultorio. Cada uno lleva su propia numeración. Esta pantalla la configura un administrador.

¿Cómo cargo un punto de expedición?

  1. Presione Agregar.
  2. Elija el Timbrado al que pertenece.
  3. Escriba el Código de 3 dígitos (por ejemplo 001) y un Nombre fácil de reconocer, como "Caja 1".
  4. Deje marcado Activo y presione Guardar.

La columna Último N° muestra el último número de factura emitido desde ese punto. El sistema sigue la numeración solo.

¿Cómo corrijo o doy de baja un punto?

Use el botón del lápiz para editarlo, o el botón rojo para eliminarlo.
