Este manual explica cómo operar la infraestructura de Sysclin: los contenedores, la configuración, la base de datos, el acceso por HTTPS, los backups y la solución de problemas. Está escrito para quien administra el servidor (soporte técnico); el administrador del consultorio no lo necesita para su trabajo diario.

No incluye las políticas de seguridad, que están en el Manual de seguridad, ni el uso de las pantallas, que explica el Manual de usuario (botón de Ayuda).

Convenciones de este manual

  • Los comandos se ejecutan en PowerShell, desde la carpeta raíz del proyecto (syscomcli), salvo que se indique otra cosa. Los marcados como bash son para el servidor Linux.
  • Donde aparece <algo>, se reemplaza por el valor real, sin los signos < >.
  • El texto que empieza con Nota: es información a tener en cuenta; el que empieza con Advertencia:, una acción que puede causar pérdida de datos o corte del servicio.
  • Las contraseñas y claves no aparecen en este manual: viven en el .env, que no se publica.
