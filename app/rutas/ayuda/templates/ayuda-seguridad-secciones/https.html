Protección de las comunicaciones

  • Todo acceso de los usuarios es por HTTPS (nginx), con TLS 1.2 o 1.3; las versiones anteriores se rechazan.
  • HTTP redirige siempre a HTTPS. En el servidor se activa HSTS por 1 año.
  • Encabezados de seguridad: X-Frame-Options: SAMEORIGIN (el sistema no se puede abrir dentro de otro sitio), X-Content-Type-Options: nosniff, Referrer-Policy: strict-origin-when-cross-origin.
  • Certificado: Let's Encrypt en el servidor, renovado cada 60 días; autofirmado solo en desarrollo.
  • La configuración de nginx es la misma en desarrollo y en el servidor; solo cambian el certificado, el HSTS y los puertos cerrados.

No alcanza con cerrar puertos con ufw en el servidor: Docker lo saltea y publica los puertos igual. Por eso el cierre se hace en docker-compose.servidor.yml, y en el servidor el sistema se levanta siempre con los dos archivos.

Ver qué puertos va a publicar cada configuración (no levanta nada):

docker compose -f dock/docker-compose.yml -f dock/docker-compose.servidor.yml config --format json | ConvertFrom-Json | ForEach-Object { $_.services.PSObject.Properties | ForEach-Object { $n=$_.Name; $_.Value.ports | ForEach-Object { "{0,-7} {1}:{2} -> {3}" -f $n, $_.host_ip, $_.published, $_.target } } }

Esperado en el servidor: 127.0.0.1 delante de 5005, 5434 y 5680; 80 y 443 sin IP.

HTTPS en desarrollo (certificado autofirmado)

# Generar el certificado (una vez; vale 825 días)
docker run --rm -v "${PWD}\dock\nginx:/nginx" postgres:17 sh /nginx/generar_cert_local.sh

# Levantar o recrear nginx
docker compose -f dock/docker-compose.yml up -d nginx

El navegador avisa que el certificado no es de confianza: es lo esperado con uno autofirmado. Se acepta una vez ("Configuración avanzada → Continuar").

Comprobar HTTPS

# Validar la configuración de nginx
docker exec syscomcli_nginx nginx -t

# HTTP redirige a HTTPS (esperado: 301 -> https://localhost/login)
curl.exe -s -o NUL -w "%{http_code} -> %{redirect_url}`n" http://localhost/login

# Encabezados de seguridad
curl.exe -sk -D - -o NUL https://localhost/login | Select-String -Pattern '^HTTP|X-Frame|X-Content|Referrer|Strict-Transport'

# Versión de TLS (esperado: TLSv1.3)
docker run --rm --network dock_network-tesis postgres:17 sh -c "echo | openssl s_client -connect nginx:443 -brief 2>&1 | grep -E 'Protocol|Ciphersuite'"

# TLS 1.1 rechazado (esperado: 000 = sin conexión)
curl.exe -sk --tlsv1.1 --tls-max 1.1 -o NUL -w "%{http_code}`n" https://localhost/login

Logs de acceso de nginx: docker logs syscomcli_nginx --tail 50.

Desplegar en el servidor

Requisitos: servidor Linux con Docker; un dominio que apunte a su IP (Let's Encrypt no emite certificados para IP); puertos 80 y 443 abiertos en el firewall del proveedor.

  1. Copiar el proyecto y crear su .env desde .env.example, con todas las claves nuevas, SESSION_COOKIE_SECURE=1 y FLASK_DEBUG=0.
  2. Obtener el certificado de Let's Encrypt. Primero se levanta nginx con un certificado autofirmado provisorio (comando de desarrollo de arriba) para que responda en el puerto 80: 
    docker compose -f dock/docker-compose.yml -f dock/docker-compose.servidor.yml up -d
docker run --rm -v "$PWD/dock/nginx/acme:/var/www/acme" -v "/etc/letsencrypt:/etc/letsencrypt" \
  certbot/certbot certonly --webroot -w /var/www/acme -d <dominio> --email <correo> --agree-tos --no-eff-email
cp -L /etc/letsencrypt/live/<dominio>/fullchain.pem dock/nginx/certs/fullchain.pem
cp -L /etc/letsencrypt/live/<dominio>/privkey.pem dock/nginx/certs/privkey.pem
docker exec syscomcli_nginx nginx -s reload
  3. Siempre levantar con los dos archivos: 
    docker compose -f dock/docker-compose.yml -f dock/docker-compose.servidor.yml up -d
  4. Comprobar HTTPS con el dominio (debe aparecer Strict-Transport-Security), que la cookie tenga Secure y que los puertos 5005, 5434 y 5680 no respondan desde otra máquina.

Renovar el certificado (servidor)

Los certificados de Let's Encrypt duran 90 días. Renovarlos cada 60; conviene programarlo con cron:

docker run --rm -v "$PWD/dock/nginx/acme:/var/www/acme" -v "/etc/letsencrypt:/etc/letsencrypt" certbot/certbot renew
cp -L /etc/letsencrypt/live/<dominio>/fullchain.pem dock/nginx/certs/fullchain.pem
cp -L /etc/letsencrypt/live/<dominio>/privkey.pem dock/nginx/certs/privkey.pem
docker exec syscomcli_nginx nginx -s reload

Ver la fecha de vencimiento del certificado instalado:

docker run --rm -v "${PWD}\dock\nginx\certs:/c:ro" postgres:17 openssl x509 -in /c/fullchain.pem -noout -subject -enddate
