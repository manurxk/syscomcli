Ver los usuarios de la base

docker exec syscomcli_bd psql -U postgres -d sysclin_bd -c "\du"

Esperado: postgres con Superuser, Create role, Create DB, Replication, Bypass RLS, y sysclin_app sin atributos. El rol y sus permisos los crea migrations/103_rol_sysclin_app.sql; las tablas, vistas y funciones que se creen después reciben los mismos permisos automáticamente.

Consola SQL

# Como administrador (todos los permisos)
docker exec -it syscomcli_bd psql -U postgres -d sysclin_bd

# Como la aplicación (permisos mínimos): para comprobar qué puede hacer la app
docker exec -it syscomcli_bd psql -U sysclin_app -d sysclin_bd

Estas consolas no piden contraseña porque se conectan desde dentro del contenedor. Desde fuera (DBeaver, otra PC) siempre se pide. Para salir: \q.

Aplicar una migración

Las migraciones están en migrations/, numeradas, y se aplican en orden, como administrador. Antes, hacer un backup manual (capítulo Backups).

Get-Content migrations\<NNN_nombre>.sql -Raw | docker exec -i syscomcli_bd psql -U postgres -d sysclin_bd -v ON_ERROR_STOP=1

ON_ERROR_STOP=1 frena al primer error, así no queda una migración aplicada a medias sin aviso.

Cambiar la contraseña de la aplicación (sysclin_app)

Cada 6 meses, o enseguida si se sospecha que se filtró. Hacerlo fuera del horario de atención: entre los pasos 2 y 3 la app no puede conectarse.

  1. Generar un valor nuevo (capítulo Configuración) y ponerlo en DB_PASSWORD del .env.
  2. Aplicarlo en la base: 
    $appPwd = (Select-String -Path .env -Pattern '^DB_PASSWORD=(.*)$').Matches[0].Groups[1].Value
Get-Content migrations\103_rol_sysclin_app.sql -Raw | docker exec -i syscomcli_bd psql -U postgres -d sysclin_bd -v ON_ERROR_STOP=1 -v "app_password=$appPwd" -q
  3. Recrear la app: docker compose -f dock/docker-compose.yml up -d app.
  4. Comprobar que responde y que se puede iniciar sesión.

Cambiar la contraseña del administrador (postgres)

  1. Generar un valor nuevo y ponerlo en POSTGRES_PASSWORD del .env.
  2. Aplicarlo en la base: 
    $admPwd = (Select-String -Path .env -Pattern '^POSTGRES_PASSWORD=(.*)$').Matches[0].Groups[1].Value
docker exec syscomcli_bd psql -U postgres -qc "ALTER ROLE postgres PASSWORD '$admPwd'"
  3. Recrear el backup para que tome la contraseña nueva: docker compose -f dock/docker-compose.yml up -d backup.
  4. Hacer un backup manual para confirmar que funciona.
  5. Actualizar la contraseña guardada en DBeaver o pgAdmin.

Con una base ya creada, cambiar solo el .env no cambia la contraseña: siempre hace falta el paso 2. Solo en una instalación nueva (volumen vacío) el contenedor crea postgres directamente con la contraseña del .env.

Comprobar los permisos de la aplicación

# Deben dar ERROR (la aplicación no puede hacerlo)
docker exec syscomcli_bd psql -U sysclin_app -d sysclin_bd -c "DROP TABLE usuarios"
docker exec syscomcli_bd psql -U sysclin_app -d sysclin_bd -c "CREATE TABLE zz_prueba (id int)"
docker exec syscomcli_bd psql -U sysclin_app -d sysclin_bd -c "TRUNCATE auditoria_sistema"

# Debe funcionar (la aplicación sí puede leer)
docker exec syscomcli_bd psql -U sysclin_app -d sysclin_bd -Atc "SELECT current_user, count(*) FROM usuarios GROUP BY 1"
